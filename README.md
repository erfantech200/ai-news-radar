# 📡 رادار خبرهای هوش مصنوعی

روزی سه بار (صبح، ظهر و شب به وقت ملبورن) این کارها خودکار انجام می‌شه:

1. **جمع‌آوری:** خبرهای تازه از بلاگ‌های OpenAI، DeepMind، گوگل، Hugging Face و NVIDIA، سایت‌های TechCrunch، MIT Technology Review و Engadget، داغ‌ترین پست‌های Hacker News و پرطرفدارترین مقاله‌های Hugging Face خونده می‌شه. منبع می‌تونه به هر زبانی باشه.
2. **حذف تکراری‌ها:** خبری که چند رسانه پوشش دادن یکی می‌شه، و خبرهایی که روزهای قبل فرستاده شدن دوباره نمیان.
3. **ایجنت سردبیر:** به هر خبر دو نمره از ۱۰ می‌ده: «اهمیت» و «ارزش ساخت محتوا».
4. **ایجنت محتوا:** برای حداکثر ۵ سوژهٔ برتر هر نوبت این‌ها رو آماده می‌کنه: تیتر فارسی، خلاصهٔ ترجمه‌شده، نکات کلیدی، «چرا مهمه» و دو ایدهٔ محتوا. هر ایده فرمت (ریلز، کاروسل و...)، هوک ثانیه‌های اول، زاویهٔ روایت، ساختار و پیشنهاد ویژوال داره.
5. **مدیا:** عکس‌ها و ویدیوهای هر خبر مستقیم توی تلگرام فرستاده می‌شن تا با یک لمس دانلودشون کنی. لینک یوتیوب و پست‌های X هم کنارش میاد.
6. **تحویل:** همه‌چیز با لینک منبع اصلی به تلگرامت میاد و یه نسخهٔ کامل هم در پوشهٔ `reports/` آرشیو می‌شه (یک فایل برای هر نوبت).

**هزینه: صفر.** GitHub Actions روی ریپوی private ماهی ۲۰۰۰ دقیقهٔ رایگان داره و این ایجنت با سه اجرا در روز ماهی حدود ۳۶۰ دقیقه مصرف می‌کنه. از Gemini هم هر نوبت فقط ۲ درخواست (روزی ۶ تا) با free tier فرستاده می‌شه.

## راه‌اندازی (یک بار، حدود ۱۰ دقیقه)

### ۱. کلید Gemini
برو [aistudio.google.com/apikey](https://aistudio.google.com/apikey) و **Create API key** رو بزن.

### ۲. ربات تلگرام
توی تلگرام به `@BotFather` پیام بده، `/newbot` رو بفرست و توکن رو بگیر. بعد **به ربات خودت یه پیام بده** (مثلاً «سلام»).

### ۳. گذاشتن کلیدها توی گیت‌هاب
مسیر: ریپو ← **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**

| اسم | مقدار |
|---|---|
| `GEMINI_API_KEY` | کلید مرحلهٔ ۱ |
| `TELEGRAM_BOT_TOKEN` | توکن مرحلهٔ ۲ |
| `TELEGRAM_CHAT_ID` | فعلاً خالی بذار. اولین اجرا خودش این عدد رو برات توی تلگرام می‌فرسته؛ بعد اینجا ذخیره‌اش کن. |

> کلیدها رو هیچ‌وقت توی کد یا چت نذار. Secrets رمزنگاری می‌شن و فقط موقع اجرا در دسترسن.

### ۴. اولین اجرا
ریپو ← **Actions** ← **Daily AI news radar** ← **Run workflow**

بعد از ۳ تا ۵ دقیقه گزارش توی تلگرامت میاد. از اون به بعد روزی سه بار خودکار اجرا می‌شه:

| ساعت ملبورن (تابستان) | چی رو پوشش می‌ده |
|---|---|
| ۷:۱۵ صبح | ظهر کالیفرنیا و بعدازظهر نیویورک |
| ۱:۱۵ ظهر | آخر روز کاری آمریکا |
| ۸:۱۵ شب | صبح اروپا و بعدازظهر چین |

هر نوبت فقط خبرهای جدید از نوبت قبل رو میاره؛ هیچ خبری دو بار نمیاد. زمستان (ساعت استاندارد ملبورن) همه یک ساعت زودتره.

## شخصی‌سازی

همه‌چیز در فایل [`config.yaml`](config.yaml) تنظیم می‌شه:

- **`profile`**: توضیح پیج، مخاطب، فرمت‌های محتوا و لحن. ایده‌ها بر اساس همین ساخته می‌شن.
- **`settings`**: تعداد سوژه‌ها (`content_items`)، تعداد خبرهای مهم دیگه، و حداقل نمره‌ها.
- **`sources`**: هر RSS به هر زبانی رو می‌شه اضافه کرد؛ خروجی همیشه فارسیه.
- **ساعت‌های اجرا**: خط‌های `cron` در [`.github/workflows/daily.yml`](.github/workflows/daily.yml). زمانش به UTC هست.

### مدل پشتیبان (اختیاری)
اگه سهمیهٔ رایگان Gemini تموم بشه، برنامه اول خودکار مدل‌های دیگهٔ Gemini رو امتحان می‌کنه. برای یه پشتیبان دیگه (مثلاً OpenRouter یا Groq، هر سرویس سازگار با OpenAI) این‌ها رو بساز:

- در **Variables**: `FALLBACK_LLM_BASE_URL` و `FALLBACK_LLM_MODEL`
- در **Secrets**: `FALLBACK_LLM_API_KEY`

ترتیب مدل‌های Gemini هم با متغیر `GEMINI_MODELS` قابل تغییره (با کاما جدا کن).

## اجرای محلی (برای توسعه)
```bash
pip install -r requirements.txt
GEMINI_API_KEY=... python main.py --dry-run   # گزارش رو چاپ می‌کنه، به تلگرام نمی‌فرسته
python -m pytest -q                          # تست‌ها، بدون اینترنت
```
